CPC Lisp -- trying it on the real 464, five-ROM set
===================================================

For the five-ROM set (python3 tools/card.py lisp, with the CPC off):

    slot 4  ROM 0  Lisp core (the CPC boots into it instead of BASIC)
    slot 5  ROM 4  library 1: screen, graphics, sound, keys, strings and
                   characters, line editor, function editor, files
    slot 0  ROM 5  library 2: floats, format, sort, lists, coerce
    slot 7  ROM 6  library 3: the functions written in Lisp (sequences...)
    slot 3  ROM 3  the demos
    slot 2  ROM 7  Parados       -- not touched
    slot 6  ROM 2  LS AI ROM     -- not touched
    slot 1  ROM 1  the vector head, as before

Every expected answer below was checked in MAME with the ROMs at these
numbers. Type each line at LISP> and press RETURN, and tick its [ ] when
you see what it says. Please note anything that differs.
docs/checklist.md lists everything that is implemented.


1. Power on
-----------
[ ] Expect, possibly after the vector head's and Parados's own messages:

    CPC Lisp 0.3, library ROMs 4 5 6 3
    NNNN cells free
    LISP>

NNNN is about 6850 in MAME; less here is fine (every ROM takes some
RAM). Please write down the number.

If the four library numbers are not all there, or the screen stays
blank: note exactly what you see and switch off.


2. Basics, and * ** ***
-----------------------
[ ] (+ 1 2)                          3
[ ] (* * 10)                         30           * is the last value
[ ] (list * ** ***)                  (30 3 NIL)   the last three values


3. Numbers, format, sort
------------------------
[ ] (sqrt 2)                         1.41421356
[ ] (sort (list 5 3 8 1) #'<)        (1 3 5 8)
[ ] (format nil "~5D|" 42)           "   42|"
                                     (the ~ is CTRL + 2 on the CPC)


4. Strings and characters
-------------------------
[ ] (string-upcase "abc")            "ABC"
[ ] (string< "apple" "banana")       0            where they differ
[ ] (string-trim " " "  hi  ")       "hi"
[ ] (string-capitalize "hello world")
                                     "Hello World"
[ ] (char< #\a #\b #\c)              T


5. Sequences and lists
----------------------
[ ] (remove #\a "banana")            "bnn"
[ ] (position 3 '(1 2 3))            2
[ ] (member "b" '("a" "b") :test #'equal)
                                     ("b")
[ ] (assoc 'b '((a . 1) (b . 2)))    (B . 2)
[ ] (reduce #'+ '(1 2 3 4))          10
[ ] (map 'string #'char-upcase "abc")
                                     "ABC"
[ ] (coerce "abc" 'list)             (#\a #\b #\c)
[ ] (remove-duplicates '(1 2 1 3))   (2 1 3)


6. The line editor
------------------
[ ] Type  (+ 1  and RETURN: the next line starts indented.
    Then type  2)  -- when you type the ")" the cursor jumps briefly to
    the matching "(". RETURN gives 3.
[ ] Type  )  on an empty line: a beep.
[ ] Cursor up brings back the last line.
[ ] SHIFT + arrows move a copy cursor and COPY copies from under it, as
    in BASIC.


7. Speed, and ESC
-----------------
[ ] (defun fib (n) (if (< n 2) n (+ (fib (- n 1)) (fib (- n 2)))))
                                     FIB
[ ] (fib 17)                         1597, after about 13 seconds
                                     (please time it)
[ ] (loop)                           runs forever; press ESC:
                                     Error: break


8. Screen mode, colours and graphics
------------------------------------
[ ] (mode 2)                         80 columns
[ ] (ink 0 0)                        black paper
[ ] (ink 1 26)                       bright white text
[ ] (border 0)                       black border
[ ] (mode 1)                         back to 40 columns
[ ] (ink 2 6)                        pen 2 is bright red
[ ] (circle 320 200 100 1)           a white circle
[ ] (disc 320 200 50 2)              a red disc inside it
[ ] (fill-box 20 20 200 100 3)       a filled box, bottom left (cyan)
[ ] (ink-mode 1)                     XOR from now on
[ ] (fill-box 100 50 300 150 2)      where it crosses the other box the
                                     colours mix
[ ] (fill-box 100 50 300 150 2)      again: it goes away
[ ] (ink-mode 0)
[ ] (cls)


9. Sound
--------
[ ] (play '(c4 e4 g4 c5))            four rising notes
[ ] (note 'a4)                       284  (the period for A 440)


10. The demos
-------------
[ ] (demo)                           the list of demos
[ ] (shapes)                         rings and bars in 16 colours; a key
                                     brings the screen back
[ ] (rose)                           a five-petal rose (takes a while)
[ ] (bounce)                         a ball bouncing, with a click at
                                     each wall; a key stops it
[ ] (sketch)                         cursor keys draw, COPY changes the
                                     colour, SPACE ends
[ ] (tune)                           Ode to Joy
[ ] (queens 6)                       a board and "4 solutions"


11. Disc, through Parados
-------------------------
Use a disc you don't mind writing to.

[ ] (dir)                            the catalogue, then NIL
[ ] (defun sq (x) (* x x))           SQ
[ ] (save "test")                    (SQ FIB)  -- what it saved
[ ] (dir)                            now shows TEST    .LSP
[ ] (load "test")                    T
[ ] (sq 12)                          144
[ ] (delete-file "test")             T, and (dir) no longer shows it
[ ] (dir "m:")                       Error: no RAM disc (M: needs a 6128)


12. Function editor
-------------------
[ ] (ed 'fib)   fib, pretty-printed, on a full screen. The cursor
                keys move, typing inserts, DEL deletes.
                COPY (or CTRL-S) reads it back in: FIB.
                ESC leaves it unchanged.
[ ] (ed 'rose)  the demo's definition (ESC to leave it)


13. Getting BASIC back
----------------------
Switch the CPC off, then on the PC:

    python3 tools/card.py basic      (silences slot 4: the core)

or type N, then slot 4, then 255 on the card's console. The other Lisp
ROMs can stay: from BASIC they do nothing. To boot into Lisp again:
python3 tools/card.py number 4 0 (CPC off).
