CPC Lisp 0.9 -- trying it on a real CPC
=======================================
A Lisp machine for the Amstrad CPC

The six ROMs on the LambdaSpeak 4 card (python3 tools/card.py lisp, with
the CPC off; the README's "Installing the ROMs" has the details):

    slot 4  ROM 0  LISP.ROM      the core: the CPC boots into it
    slot 5  ROM 4  LISPLIB.ROM   library 1: screen, graphics, sound, keys,
                                 strings, streams, editors, files
    slot 0  ROM 5  LISPLIB2.ROM  library 2: floats, format, sequences,
                                 structures, hash tables, the card
    slot 7  ROM 6  LISPLIB3.ROM  library 3: the functions written in Lisp
    slot 3  ROM 3  LISPDEMO.ROM  loop, string streams, the demos
    slot 1  ROM 1  LISPVM.ROM    the compiler and its bytecode machine
    slot 2  ROM 7  Parados       -- not touched
    slot 6  ROM 2  LS AI ROM     -- not touched

Every expected answer below was checked in MAME with the ROMs at these
numbers. Type each line at LISP> and press RETURN, and tick its [ ] when
you see what it says. Please note anything that differs.
docs/checklist.md lists everything that is implemented. Sections 1-13
were checked on the real 464 with the five-ROM set (2026-11-07); what
was checked since is noted at the end of each section.


1. Power on
-----------
[ ] Expect, possibly after Parados's own message:

    CPC Lisp 0.9
    A Lisp machine for the Amstrad CPC
    library ROMs 4 5 6 3
    NNNN cells free
    LISP>

NNNN is about 6650 in MAME without a disc ROM; less here is fine (every
ROM takes some RAM). The VM ROM is not listed. If the four library
numbers are not all there, or the screen stays blank: note exactly what
you see and switch off.


2. Basics, and * ** ***
-----------------------
[ ] (+ 1 2)                          3
[ ] (* * 10)                         30           * is the last value
[ ] (list * ** ***)                  (30 3 NIL)   the last three values


3. Numbers, format, sort
------------------------
[ ] (sqrt 2)                         1.41421356
[ ] (sort (list 5 3 8 1) #'<)        (1 3 5 8)
[ ] (format nil "~5D|" 42)           "   42|"
                                     (the ~ is CTRL + 2 on the CPC)


4. Strings and characters
-------------------------
[ ] (string-upcase "abc")            "ABC"
[ ] (string< "apple" "banana")       0            where they differ
[ ] (string-trim " " "  hi  ")       "hi"
[ ] (string-capitalize "hello world")
                                     "Hello World"
[ ] (char< #\a #\b #\c)              T


5. Sequences and lists
----------------------
[ ] (remove #\a "banana")            "bnn"
[ ] (position 3 '(1 2 3))            2
[ ] (member "b" '("a" "b") :test #'equal)
                                     ("b")
[ ] (assoc 'b '((a . 1) (b . 2)))    (B . 2)
[ ] (reduce #'+ '(1 2 3 4))          10
[ ] (map 'string #'char-upcase "abc")
                                     "ABC"
[ ] (coerce "abc" 'list)             (#\a #\b #\c)
[ ] (remove-duplicates '(1 2 1 3))   (2 1 3)


6. The line editor
------------------
[ ] Type  (+ 1  and RETURN: the next line starts indented.
    Then type  2)  -- when you type the ")" the cursor jumps briefly to
    the matching "(". RETURN gives 3.
[ ] Type  )  on an empty line: a beep.
[ ] Cursor up brings back the last line.
[ ] SHIFT + arrows move a copy cursor and COPY copies from under it, as
    in BASIC.


7. Speed, and ESC
-----------------
[ ] (defun fib (n) (if (< n 2) n (+ (fib (- n 1)) (fib (- n 2)))))
                                     FIB
[ ] (fib 17)                         1597, after about 13 seconds
                                     (please time it)
[ ] (loop)                           runs forever; press ESC:
                                     Error: break


8. Screen mode, colours and graphics
------------------------------------
[ ] (mode 2)                         80 columns
[ ] (ink 0 0)                        black paper
[ ] (ink 1 26)                       bright white text
[ ] (border 0)                       black border
[ ] (mode 1)                         back to 40 columns
[ ] (ink 2 6)                        pen 2 is bright red
[ ] (circle 320 200 100 1)           a white circle
[ ] (disc 320 200 50 2)              a red disc inside it
[ ] (fill-box 20 20 200 100 3)       a filled box, bottom left (cyan)
[ ] (ink-mode 1)                     XOR from now on
[ ] (fill-box 100 50 300 150 2)      where it crosses the other box the
                                     colours mix
[ ] (fill-box 100 50 300 150 2)      again: it goes away
[ ] (ink-mode 0)
[ ] (cls)


9. Sound
--------
[ ] (play '(c4 e4 g4 c5))            four rising notes
[ ] (note 'a4)                       142  (the period for A 440)


10. The demos
-------------
[ ] (demo)                           the list of demos
[ ] (shapes)                         rings and bars in 16 colours; a key
                                     brings the screen back
[ ] (rose)                           a five-petal rose (takes a while)
[ ] (bounce)                         a ball bouncing, with a click at
                                     each wall; a key stops it
[ ] (sketch)                         cursor keys draw, COPY changes the
                                     colour, SPACE ends
[ ] (tune)                           Ode to Joy
[ ] (queens 6)                       a board and "4 solutions"


11. Disc, through Parados
-------------------------
Use a disc you don't mind writing to.

[ ] (dir)                            the catalogue, then NIL
[ ] (defun sq (x) (* x x))           SQ
[ ] (save "test")                    (SQ FIB)  -- what it saved
[ ] (dir)                            now shows TEST    .LSP
[ ] (load "test")                    T
[ ] (sq 12)                          144
[ ] (delete-file "test")             T, and (dir) no longer shows it
[ ] (dir "m:")                       on a 464 without a RAM expansion:
                                     Error: no RAM disc (M: needs 128 KB)


12. Function editor
-------------------
[ ] (ed 'fib)   fib, pretty-printed, on a full screen. The cursor
                keys move, typing inserts, DEL deletes.
                COPY (or CTRL-S) reads it back in: FIB.
                ESC leaves it unchanged.
[ ] (ed 'rose)  the demo's definition (ESC to leave it)
[ ] (ed 'queens) SHIFT + down: a page down; SHIFT + up: back up. CTRL +
                up/down: the top/bottom. ESC to leave it.


13. Speech, the turtle, and more
-------------------------------
Speech is the one thing MAME cannot check -- it has no LambdaSpeak.

[ ] (say "Hello from Lisp")         the card speaks it (DECtalk), and
                                     LISP> comes back at once
[ ] (speech-voice 3) (say "I am Betty")
                                     a woman's voice
[ ] (sing)                           "I am a Lisp machine", sung up a
                                     chord
[ ] (talk)                           two sentences
[ ] (chords)                         PlayCity: four six-note chords
[ ] (koch 4)                         a Koch snowflake; a key ends it
[ ] (tree)                           a tree
[ ] (progn (forward 100) (right 90) (forward 100) (turtle-position))
                                     a line up and one right; (420 300)
[ ] (read-line)  then type  hello    "hello"
[ ] (y-or-n-p "OK?")  then  y        T
[ ] (floor 7 2)                      3 and 1, on two lines
[ ] (defstruct point x y)            POINT
[ ] (make-point :x 1 :y 2)           #S(POINT 1 2)
[ ] (setq h (make-hash-table))  (setf (gethash 'a h) 1)  (gethash 'a h)
                                     1 and T
[ ] (position #\a "banana" :from-end t)
                                     5
[ ] (progn (cls) (circle 320 200 80) (flood-fill 320 200 2))
                                     the circle filled (a few seconds)
[ ] (symbol 240 60 66 165 129 165 153 66 60) (princ (code-char 240))
                                     a smiley



14. Files as streams, through Parados
-------------------------------------
Only the card's disc can tell -- MAME has AMSDOS. Use a disc with room.
Two files open at once is the point of the last steps.

[ ] (with-open-file (o "t1" :direction :output) (format o "~{~A~%~}" '(one two three)))
                                     NIL
[ ] (with-open-file (i "t1") (list (read-line i) (read-line i)))
                                     ("ONE" "TWO")
[ ] (defun cp (a b) (with-open-file (i a) (with-open-file (o b :direction :output) (loop for l = (read-line i nil nil) while l do (write-line l o)))))
                                     CP
[ ] (cp "t1" "t2")                   NIL, no error
[ ] (with-open-file (i "t2") (loop for l = (read-line i nil nil) while l collect l))
                                     ("ONE" "TWO" "THREE")
[ ] (dir)                            T1.LSP and T2.LSP, the same size

A photo of the screen is as good as ticks.
(Checked on the 464 through Parados, 2026-11-07, build 4326: all as
above.)


15. The line editor at the screen's edge
---------------------------------------
[ ] (dotimes (i 30) (print i))   then, at the bottom of the screen, type a
    line longer than the screen is wide:
    (list 'aaaaaaaaaa 'bbbbbbbbbb 'cccccccccc 'dddddddddd)
                                     it goes on at the next row, the screen
                                     scrolling once -- not a row a key
[ ] (mode 2), then a line longer than 80 characters:
    (format nil "~{~A~}" (loop for i below 100 collect (mod i 10)))
    then SHIFT + up to the first row of the digits, and COPY held down
                                     the copy goes on at the start of the
                                     next row: ...789 then 0123...
(Checked on the 464, 2026-11-07, build 5743: both as above.)


16. The compiler
----------------
[ ] (defun fib (n) (if (< n 2) n (+ (fib (- n 1)) (fib (- n 2)))))
    (fib 17)                         1597, in about 13 s
[ ] (compile 'fib)                   FIB, in about 2 s
    (fib 17)                         1597, in about 4 s
[ ] (disassemble 'fib)               about 16 lines, ENTER 1 ... RET
[ ] A disc, through Parados:
    (defun sq (x) (* x x))
    (save "sq")                      (SQ)
    (compile-file "sq")              ;; 1 compiled   "sq.FAS"
    (fmakunbound 'sq)
    (load "sq.fas")                  T
    (sq 12)                          144
(Checked on the 464, 2026-11-07, build 22482: compile and the
compile-file round trip through Parados.)



17. The 664/6128 firmware, and a RAM expansion
----------------------------------------------
With BASIC 1.1 firmware in the 464 (or on a 6128):
[ ] (sqrt 2)                         1.41421356
[ ] (- 10.5 0.25)                    10.25
[ ] (sin 1.0)                        0.841470985
[ ] (format nil "~,3F" pi)           "3.142"
[ ] (rose)                           a rose; a key ends it
[ ] the line editor and ESC, as in sections 6 and 7; the compiler, as in
    section 16
With a RAM expansion (or a 6128), under either firmware:
[ ] (defun sq (x) (* x x))  (save "m:sq")
                                     (SQ)
[ ] (dir "m:")                       Drive M: (RAM)  SQ.LSP  ...  bytes free
[ ] (fmakunbound 'sq)  (load "m:sq")  (sq 9)
                                     T, then 81
(Checked on the 464 with an unofficial 1.1 firmware ROM and a RAM
expansion, 2026-11-07, build 22482: all as above; the RAM disc under the
1.0 firmware too.)


18. Getting BASIC back
----------------------
Switch the CPC off, then on the PC:

    python3 tools/card.py basic      (silences slot 4: the core)

or type N, then slot 4, then 255 on the card's console. The other Lisp
ROMs can stay: from BASIC they do nothing. To boot into Lisp again:
python3 tools/card.py number 4 0 (CPC off).
